搜索页上谁都说模型多、延迟低、便宜。对企业采购，危险也在这里——**单价和模型数量，偏偏最好包装。**

2026 年前后，安全研究与行业复盘里反复出现同一类问题：有的第三方通道声称官方模型，实际用更便宜的开源或降级模型顶替；有的靠网页逆向硬撑 API 形态，账号一封就全站抖。学术侧甚至专门审计过“影子 API”与官方输出不一致的现象——你不必读论文，但要知道：**实验可以赌通道，生产流量不行。**

选型别从评分表背起。先学会把假通道问穿，再按你的主场景挑能力；自建还是托管，最后再定。

## 先把低价陷阱问穿（可直接粘贴进询价）

当面或邮件里，让对方用人话回答，答含糊就降权：

1. **“这个 Claude / GPT 型号，通道是官方 API、转售，还是自建推理？有没有网页逆向？”**  
   说不清来源，或强调“和官方差不多你测不出来”，生产慎用。

2. **“能否按模型标注通道类型？供应商变更或下线时，切换策略是什么？”**  
   列表很长却来路不明，不如来源清晰的短列表。

3. **“单价显著低于官方时，差价从哪来？是否存在降级、掺水、缓存顶替？”**  
   长期远低于合理成本的报价，往往伴随不可持续渠道或模型替换风险。社区里“一折官模”“无限量”一类广告，和企业生产需求通常不在同一条赛道。

4. **“给我一笔可对账的调用明细：输入 / 输出 / 缓存 Token 分项，能否按 Key、项目导出？”**  
   只有充值余额、没有分项，财务和 CTO 都会难受。企业真正怕的不是贵，是**不可解释的贵**。

5. **“主模型不可用时，自动降到哪？限流是排队、拒绝还是静默失败？有无可用性说明？”**  
   没有限流与 fallback 的中转，只是把单点故障从厂商挪到了中转商。

6. **“对公主体、合同、发票怎么走？出事后 2 小时内谁响应？”**  
   个人收款、出事只说“再等等 / 换个 Key”，不适合进生产。

常见低价陷阱还长这样：无限量或永久套餐却暗藏频次封禁；模型列表很长却测不出与官方行为一致；承诺高并发却无任何可用性说明。**省下的钱，往往不够一次事故。** 首次接入建议小额试水，别一上来充年费。

## 做一次对照实验，比再听一小时销售更值

通道说辞听完之后，用同一组真实 Prompt 做对照，比继续比价表更有效：

- 选 3 个真实 Prompt：短文本、长上下文、工具调用各一；
- 同一 Prompt 在官方控制台（或你们已信任的通道）与候选中转各跑一遍；
- 看工具调用字段、拒绝策略、长上下文表现是否明显走样；
- 人为制造主模型不可用，看降级是否自动；
- 导出几天调用明细，让财务能否看懂；
- 试一次 Key 回收与权限变更，看是否顺手。

走样不一定立刻否定，但对方必须解释清楚——是路由策略、是模型降级，还是通道根本不是你以为的那条。答不上来，就不要把生产切过去。若候选方拒绝提供测试额度、不允许导出明细、或要求先充大额才能试用，这本身就是选型信号：企业采购应能小步验证，而不是先交信任税。

## 通道清楚之后，再看工程能不能接住

协议缺口会表现为：Demo 能跑，Claude Code、Agent 框架、内部 SDK 频繁报错。至少确认：是否提供 OpenAI 兼容接口；Anthropic 等原生协议是否需要魔改；流式、工具调用、多模态字段能否完整透传。

企业管理最小清单：子账号 / 项目隔离、Key 轮换与回收、调用审计、敏感操作留痕、国内业务常见的合同主体是否清晰。开源自建（如基于 LiteLLM / One API / New API 一类）适合有运维力量、愿意自己扛 SLA 的团队；更想“托管 + 可运维”，就评估服务商的部署与值守，而不是只买一个充值账号。

国产模型（DeepSeek / Qwen / GLM 等）为主时，额外看：国内访问延迟是否稳；是否接得住你们已有的 OpenAI 兼容工具链；中高用量价格阶梯是否友好；与海外模型并存时路由好不好配。“国产为主”不等于“只要便宜”——生产依然要审计、限流与发票。

## 按你的主场景对号，别追总榜第一

| 你现在最头疼的事 | 选型时优先盯什么 |
| --- | --- |
| 线上不能挂，客户能感知 | 可用性说明、自动降级、审计日志、能开票 |
| 预算紧，国产推理为主 | 延迟是否稳、阶梯价是否透明、别只看标价最低 |
| 好几家模型混着用 | 统一协议、路由策略、按项目拆账 |
| 先验证值不值得做 | 开通快、按量、绑定少；别一上来充年费 |
| 政企 / 强合规 | 合同主体、合规通道、日志留存期限 |

同一张表也可以反过来用：如果供应商只会吹“模型最多、全网最低”，却答不上你这一行的优先项，名单可以直接划掉。通道真实性、账单可解释、故障可降级——这三件事过了，再谈单价才有意义。
