企业问得最多的一句话不是“你们贵不贵”，而是：**讲完之后，我们的人到底会什么？**

不承诺“三天培养算法专家”。我们承诺的是：在约定天数里，让参训人员带着可复用的方法与可演示的成果离开教室。下面用一场标准全天课当切片，把醴陵真好的 AI 讲课摊开说。

## 主线先钉死，再谈上午下午怎么切

2026 年有效的企业 AI 培训，正在从“学工具”转向“学会与 AI 协同、甚至搭一条可演示的小智能体”。我们的主线也按这个变化来排：

> 定义任务 → 写清约束 → 产出可验收结果 → 固化成模板 / 工作流 →（可选）升级为 Agent

课堂上的每次练习都尽量逼近真实工作，而不是停留在“模型很厉害”的观感。以 **企业 AI 内训 ¥8,000/天**（全天，含课程定制与实操，支持开票；培训后 7 天答疑）为例，比例会按岗位结构调整，但节奏大致如下。

## 上午：先把问题说清楚（否则下午全白练）

- 大模型能力边界：擅长什么、翻车常见在哪里；
- 企业场景地图：哪些工作适合增强、哪些必须人工终审；
- 安全与合规底线：敏感数据、对外发布、版权与责任归属；
- 任务拆解练习：把“写个方案”改写成可执行的输入结构。

很多企业在这一步就会发现：之前不是模型不行，是需求本身含糊。管理层若只来半天，重点会停在“能做 / 不能做 / 试点怎么验收”，而不是会敲 Prompt。

## 下午：没有带走物，就不算下课

- Prompt 工程：角色、上下文、约束、示例、验收标准；
- 用企业真实材料练：产品说明、客诉、合同摘要、周报；
- 工作流入门：何时用聊天，何时该上 Dify / Coze / n8n 一类编排；
- 小组路演：每组提交一个“可带走”的模板或小流程。

实操不是“看老师点几下”。通常会提前收集脱敏材料（或现场用公开可替代样本起步）；按岗位分组，每组只攻一个场景；强制写出验收标准；互相质检——一组产出，另一组按清单挑错；最后收束成可共享的模板文档。

现场我们常做的取舍：宁可少讲两个热门工具，也要把“验收标准怎么写”练透。工具三个月后可能换，验收习惯不会。有一次客户坚持全天只听不练，我们当场把预期改成“认知对齐”，并建议另约实操日——讲座式能扫盲，带不走模板。这种节奏会比纯演讲累，但转化率高。

## 不同对象，带走物不一样

课纲按岗位产出写，不按“模型名词表”写。

### 管理层（0.5–1 天）

重点不是会敲 Prompt，而是会拍板：AI 投入优先级怎么排；试点指标怎么定（时效、差错率、人效，而不是“用了多少次”）；组织上要补的角色——业务 owner、数据负责人、IT 对接人。**带走物**：一页试点优先级表 + 三周验收口径。

### 业务岗（1–2 天）

| 岗位示例 | 课堂练什么 | 带走什么 |
| --- | --- | --- |
| 销售 | 客户纪要 → 跟进邮件 / 方案提纲 | 本岗位 Prompt 模板 + 发出前质检清单 |
| 客服 | 工单/话术 → 标准回复草案 | 敏感场景人工终审规则 |
| 运营 / 行政 | 周报、活动说明、制度摘要 | 部门共享模板库骨架 |
| 项目经理 | 会议纪要 → 风险与待办 | 可复用的纪要结构 |

### 技术 / 数字化岗（2–3 天或分段）

在业务课基础上加深：RAG 知识库的基本链路与常见坑；Agent 的工具调用与权限边界；评测集怎么建（没有评测，就没有迭代）；与企业 API 中转、私有化部署如何衔接。**带走物**：一条可演示的小闭环（检索或工具调用）+ 起步评测题若干条。

## 我们会讲、也会劝你别指望的

**会讲：** Prompt 与上下文工程的可复用写法；从单次对话到工作流 / Agent 的升级路径；如何用小样本评测防止“演示很好、上线很崩”；如何把培训成果接到后续项目（API 网关、本地 Agent、FDE）。

**不会虚构承诺：** 不保证培训后营收翻倍；不把尚未验证的行业黑话包装成“独家秘籍”；不鼓励把核心机密数据随意粘贴到不明来源的公共工具。

## 三周后怎么自检“值不值”

我们建议企业用三周窗口自检，而不是看结业合影：

1. **第 1 周**：参训人员是否开始按约定模板干活（频率比“用过几次 AI”更重要）；
2. **第 2 周**：是否形成一个部门级共享 Prompt / SOP 文档；
3. **第 3 周**：是否选出 1 个场景进入自动化或 Agent 试点清单。

若三周后只有聊天记录、没有模板沉淀，问题通常出在管理推动，而不只是课程。答疑期内我们可以一起纠偏——但纠不了“没有人愿意当模板 owner”这件事，这要你们内部拍板。
