客户最怕两种报价：一种是“AI 系统一口价”，什么都含又什么都不含；另一种是低价进门，上线后每一项都算增购。

我们把本地 Agent 拆成清晰版本，方便你对照阶段选择。价格以 [服务价格](/pricing) 为准。2026 年私有化 Agent / RAG 的交付周期，市场上从数周单场景到数月多系统集成都有——关键不是口号里的“快”，而是**范围是否锁死、语料是否可用、集成有多深**。企业侧讨论里反复强调：权限要在检索层做（别指望模型自己“懂保密”），混合检索比裸向量更稳，上线前要有评测集——这些都会反映进交付范围，而不是演示稿里的一笔带过。

## 先看“单场景上线”到底值不值

在谈版本之前，先判断你的问题是否适合标准版这种**单场景项目制**：

- 这类问题每周是否反复出现？
- 答案是否主要来自既有文档，而非口头默契？
- 出错时是否允许人工兜底？

三个都满足，单场景上线通常能在几周到一季内看见使用量。缺一条，先补培训或先整理语料往往更划算——别用 Agent 预算去买本该先做的数据治理。

单场景解决的是：把高频、可界定的一类问题，从“找人翻资料”变成“系统辅助 + 人确认”。它不承诺一夜替换全公司入口，也不默认打通所有业务写回。

## 三个版本：价、包含、不包含

### Agent 标准版 · ¥50,000 起

**适合：** 已有明确单场景，希望私有化落地并带知识库接入。常见例子：

- 内部制度 / 工艺问答：新员工和班组长在权限内问到带出处的答案；
- 售后回复草稿：客服对着工单生成初稿，人工确认后发出；
- 项目资料检索：售前 / 实施在约定语料里找方案片段。

**通常包含：** 需求澄清与场景边界确认；私有化部署方案；RAG 知识库接入（约定语料范围）；基础权限与访问控制；**1 个月**技术支持。

**不默认包含：** 大规模历史数据治理、多系统深度写回、多 Agent 编排、长期驻场。

### Agent 企业版 · ¥120,000 起

**适合：** 多个角色协作、需要工具链集成与更细权限，或要把 Agent 嵌进审批 / 工单等流程。相对标准版，更强调多 Agent 协作与工作流编排、多工具链集成、更完整的权限管理，以及 **3 个月**技术支持。

企业版仍然建议分场景上线：先让一个流程稳定，再扩相邻角色。一天切换全公司入口，组织消化不了。若痛点其实是“文档找不到”，先标准版或单独 RAG 更诚实；若痛点是“多系统审批里要自动起草 + 回写”，企业版才对得上问题。

### RAG 知识库建设 · ¥20,000 起

有些企业云端模型已经在用，缺的是把文档变成可检索资产。单独建设时关注：数据清洗与入库、检索效果优化、管理后台（约定范围）、与后续 Agent 的接口预留。

知识库质量决定上限。文档极度分散、格式混乱时，我们会在评估后如实告知治理工作量，而不是假装“导入即可智能”。也可以先做 RAG，再升级到 Agent 标准版：先让检索可用，再让工具会动手。

## 硬件与模型：我们怎么谈、怎么不谈

我们会根据延迟、并发、是否必须断网、预算，给出模型与硬件建议区间。不会为了抬高报价默认上最贵卡；也不会在明显算力不够时硬撑“也能跑”。若已有服务器或信创约束，请在评估阶段一并告知。

我们倾向可审计、可交代的技术路线，避免把客户锁死在无法导出的黑盒里。但这不等于把未经硬化的社区 Demo 直接扔进生产——交付会包含必要的权限、日志与运维加固，这正是项目费用的一部分。2026 年私有化讨论里，数据不出域与操作可审计已是刚需，不是可选项。

## 周期 4–12 周：什么拉向下限，什么拉向上限

公开口径里，Agent 定制类项目常在 **4–12 周**：

- 单场景 + 语料整齐：靠近下限；
- 多系统集成 + 权限复杂：靠近上限，甚至需要改走 / 搭配 FDE。

启动后若发现语料质量远差于评估时的样例，周期会外延——这不是“开发慢”，而是知识治理被低估了。我们会在评估阶段尽量把这个风险说在前面，并给出：先做 RAG 清洗、还是缩小场景、还是暂缓立项。

API 中转（约 1–2 周）与培训（按天）可以并行，用来降低“等 Agent 上线期间团队完全不会用”的空窗。

## 验收五问 + 售后边界（写进合同更省事）

验收会上请业务 owner 到场——只有 IT 点头、一线没用过，不算真正验收。一起确认：

1. 核心问题集的表现是否达到约定阈值？
2. 权限抽检是否发现越权回答？
3. 知识更新流程是否有负责人？
4. 故障时如何回退到人工流程？
5. 内部是否有人能完成日常运维操作？

**售后：** 技术支持期内含缺陷修复、使用问题、约定范围内的调优；支持期外可续维保，或转为按次 / 驻场。明显超范围的新场景重新评估，不硬塞进原合同。支持期不是无限改需求的窗口——把“新场景”和“原场景调优”分开说，双方都省心。

## 启动前尽量准备这五样

1. 场景负责人（业务侧一人即可）；
2. IT / 网络对接人；
3. 脱敏后的样例数据；
4. 现有系统清单（若需要集成）；
5. 成功标准（哪怕先定三个指标）。
