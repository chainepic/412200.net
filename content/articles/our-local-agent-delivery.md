客户最怕两种报价：一种是“AI 系统 一口价”，什么都含又什么都不含；另一种是低价进门，上线后每一项都算增购。

我们把本地 Agent 相关服务拆成清晰版本，方便你对照自己的阶段选择。价格以 [服务价格](/pricing) 为准。

## 标准版：先打通一个真场景

**Agent 标准版 · ¥50,000 起**

适合：已有明确单场景（例如内部制度问答、售后草稿助手、项目资料检索），希望私有化落地并带知识库接入。

通常包含：

- 需求澄清与场景边界确认；  
- 私有化部署方案；  
- RAG 知识库接入（在约定语料范围内）；  
- 基础权限与访问控制；  
- **1 个月**技术支持。

不默认包含：大规模历史数据治理、多系统深度写回、多 Agent 编排、长期驻场。

## 企业版：多 Agent 与工作流

**Agent 企业版 · ¥120,000 起**

适合：多个角色协作、需要工具链集成与更细权限，或要把 Agent 嵌进审批 / 工单等流程。

相对标准版，更强调：

- 多 Agent 协作与工作流编排；  
- 多工具链集成；  
- 更完整的权限管理；  
- **3 个月**技术支持。

企业版仍然建议“分场景上线”，而不是一天切换全公司入口。

## RAG 知识库建设：可以单独做

**¥20,000 起**

有些企业云端模型已经在用，缺的是把文档变成可检索资产。单独建设知识库时，我们关注：

- 数据清洗与入库；  
- 检索效果优化；  
- 管理后台（按约定范围）；  
- 与后续 Agent 的接口预留。

知识库质量决定上限。若文档极度分散、格式混乱，我们会在评估后如实告知治理工作量，而不是假装“导入即可智能”。

## 交付过程中，你需要准备什么

为了避免项目空转，启动前请尽量准备：

1. 场景负责人（业务侧一人即可）；  
2. IT / 网络对接人；  
3. 脱敏后的样例数据；  
4. 现有系统清单（若需要集成）；  
5. 成功标准（哪怕先定三个指标）。

我们提供开源可审计框架路线，强调**数据不出企业内网**的方案选项；具体模型与硬件会按现场约束给出建议。

## 周期怎么理解

公开口径里，Agent 定制类项目常在 **4–12 周**，复杂度决定位置：

- 单场景 + 语料整齐：靠近下限；  
- 多系统集成 + 权限复杂：靠近上限甚至需要 FDE 模式。

API 中转（1–2 周）与培训（按天）可以并行，用来降低“等 Agent 上线期间团队完全不会用”的空窗。

## 售后边界（写清楚反而更省心）

技术支持期内：缺陷修复、使用问题、约定范围内的调优。  
支持期外：可续维保，或转为按次 / 驻场。  
明显超范围的新场景：重新评估，不硬塞进原合同。

带上你的场景一页纸（没有的话，沟通时我们帮你写），微信搜「醴陵真好」或发邮件至 contact@412200.net。我们会告诉你更适合标准版、企业版，还是先做培训 / 咨询再立项——而不是默认把所有客户推进最贵的一档。


## 验收会上我们希望一起确认的问题

1. 核心问题集的表现是否达到约定阈值？
2. 权限抽检是否发现越权回答？
3. 知识更新流程是否有负责人？
4. 故障时如何回退到人工流程？
5. 内部是否有人能完成日常运维操作？

五问过关，项目才算真正交到你手里，而不是“还能聊两句”。

## 硬件与模型：我们怎么给建议

我们会根据场景延迟、并发、是否必须断网、预算，给出模型与硬件建议区间。不会为了抬高报价默认上最贵卡；也不会在明显算力不够时硬撑“也能跑”。若你们已有服务器或信创约束，请在评估阶段一并告知，避免方案返工。
## 与开源社区版本的关系

我们倾向可审计、可交代的技术路线，避免把客户锁死在无法导出的黑盒里。但这不意味着“把未经硬化的社区 Demo 直接扔进生产”。交付会包含必要的权限、日志与运维加固，这正是项目费用的一部分。

也可以先做 RAG 知识库，再升级到 Agent 标准版：先让检索可用，再让工具会动手。分步投入，比一次性梭哈更容易在组织内获得信任。
